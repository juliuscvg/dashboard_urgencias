# Iteraciones Urgencias

Las tareas sustanciales se especifican aquí como `ITER-XXX.md`.

Instrucción mínima de arranque para el agente:

```text
Sincroniza main con origin/main mediante fast-forward.
Lee AGENTS.md y docs/gobierno/CHECKPOINT_ACTUAL.md.
Ejecuta docs/iteraciones/ITER-XXX.md.
No amplíes alcance. Haz commit/push y detente.
```

Usar como referencia la plantilla transversal `dashboard_hcg_specs/templates/ITERACION_MULTIAGENTE.md`.

Cada iteración debe ser acotada, con criterios de aceptación verificables, y no debe duplicar decisiones ya documentadas en gobierno.
